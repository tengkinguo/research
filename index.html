AI 学习路径概览

从零基础到研究实践的一个可能路线，仅供参考，可根据个人背景调整顺序与深度。

建议：至少完整走完一个路径，再横向扩展

阶段 1 · 基础入门

目标：理解 AI / ML 的基本概念与常见术语，建立整体认知。

  • 了解 AI、机器学习、深度学习、LLM 的区别与联系
  • 熟悉 Python 基础语法与常用库（NumPy / Pandas / Matplotlib）
  • 浏览一门机器学习入门课程的大纲，形成知识地图

阶段 2 · 数学基础

目标：能够看懂主流教材中的数学符号与核心推导。

  • 线性代数：向量、矩阵、特征值、奇异值分解
  • 概率统计：随机变量、分布、极大似然、贝叶斯公式
  • 微积分：函数、导数、偏导、梯度下降的直观理解

阶段 3 · 经典机器学习

目标：掌握监督 / 非监督学习的基本方法及使用场景。

  • 线性回归、逻辑回归、决策树、随机森林、SVM
  • 聚类（K-Means）与降维（PCA 等）
  • 使用 scikit-learn 完成若干小项目（预测 / 分类 / 聚类）

阶段 4 · 深度学习与表示学习

目标：理解神经网络的基本结构与训练方法。

  • 前向传播 / 反向传播、损失函数与优化器
  • CNN、RNN、Attention、Transformer 等主流结构
  • 使用 PyTorch / TensorFlow 复现经典模型（如 MNIST、文本分类）

阶段 5 · 大模型与应用实践

目标：掌握 LLM 的基本原理与常见应用范式。

  • 理解 Transformer、预训练、微调、对齐等关键概念
  • 熟悉 Prompt Engineering、RAG、工具调用、Agent 等模式
  • 结合开源模型或 API 完成一个端到端的小项目

阶段 6 · 论文阅读与研究实践

目标：能够独立阅读主流 AI 会议论文并尝试复现或改进。

  • 选择 1~2 个细分方向，建立论文阅读清单
  • 尝试代码复现与对比实验，记录实验日志
  • 在公开仓库整理笔记与代码，形成个人研究档案

AI 学习与研究资源导航

以下为常见的资源类别示例，可根据个人习惯补充或替换为你常用的网站与教材。

公开课 / 视频课程

  • 机器学习入门： 可选 Coursera、Udacity、B 站高校公开课等平台

实战建议与学习习惯

理论必须与实践结合，通过持续的小项目、复现与总结，逐步形成自己的知识体系。

实战与项目建议

  1. 由小到大，逐步增加难度。 从简单的分类 / 回归任务开始，慢慢尝试更复杂的数据与模型。
  2. 保证每个项目都可复现。 清晰记录依赖环境、数据来源、训练参数和评测指标。
  3. 建立统一的笔记与代码仓库。 为每个项目写一份 README，简要说明问题背景、方法与结论。
  4. 定期回顾总结。 每 1~2 个月整理一次「学到了什么、还不清楚什么、下一步计划是什么」。
  5. 适度阅读开源项目。 选择少数高质量仓库深入阅读，而不是广泛但浅尝辄止。

日常学习流程示例

  • Step 1 · 输入： 视频 / 教材 / 论文，控制在可消化的篇幅
  • Step 2 · 输出： 将新知识转化为自己的语言，用图示或小结说明
  • Step 3 · 实践： 用代码或实验来验证理解，不要求复杂，但要完整可运行
  • Step 4 · 记录： 将关键发现、坑点和思考写入统一笔记系统
  • Step 5 · 分享： 选择适合的渠道对外分享，倒逼自己讲清楚问题与答案
